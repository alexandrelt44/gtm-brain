# Moléculas

Componentes formados por dois ou mais átomos: abas, menu suspenso, modal, formulário, tooltip, barra de busca, paginação, trilha de navegação (breadcrumbs).

## Vazia de propósito

Esta pasta vem vazia para você não cair na tentação de copiar specs velhas que talvez não batam com a sua interface. Acrescente as moléculas que o seu produto realmente usa, com o modelo em [`../../MODELO-DE-SPEC.md`](../../MODELO-DE-SPEC.md). Uma camada de specs pequena e precisa vale mais que uma completa e desatualizada.

## Ordem sugerida para produtos de pequenas e médias empresas

1. `formulario.md` (rótulo + campo + texto de ajuda + erro)
2. `barra-de-busca.md` (ícone + campo + botão de limpar)
3. `modal.md` (fundo escurecido + contêiner + cabeçalho + ações)
4. `tooltip.md`
5. `abas.md`
6. `menu-suspenso.md`
7. `paginacao.md`
8. `trilha-de-navegacao.md`
