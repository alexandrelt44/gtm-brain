# Palavras simples

A ideia vem das campanhas de linguagem simples: trocar a palavra pomposa pela que o leitor usa. A lista abaixo foi refeita para o português do Brasil. Use para montar a tabela `## Termos proibidos` do `TERMINOLOGIA.md` e para revisar rascunhos.

Não copie a lista inteira para o arquivo da marca. Escolha as palavras que aparecem nos textos dela, nos rascunhos dos agentes ou no jargão da categoria. Uma tabela curta e verdadeira vale mais que uma longa e genérica.

Antes de proibir uma palavra, confira a `VOZ-DO-CLIENTE.md`. Se o cliente usa a palavra, ela pode ser a certa.

| --- | --- |

| conforme supracitado | como dissemos |

| disponibilizar | dar, oferecer, pôr no ar |
| efetuar, realizar | fazer |
| encontra-se | está |

| estar efetuando, vou estar enviando | faço, vou enviar |

| mediante | com, por |
| no que tange a, no que diz respeito a | sobre |

## Jargão de dentro

Palavras que o time usa e o cliente não. Em texto público, troque. Em documento interno, tudo bem.

| Jargão | Para o cliente |
| --- | --- |
| funil | jornada de compra, ou corte |
| lead | contato, pessoa interessada |
| onboarding | começo, implantação, primeiros dias |
| churn | cancelamento |
| ticket médio | valor médio por cliente |
| stack | conjunto de ferramentas |
| SMB, PME | pequena empresa, ou o segmento |
| solução | o nome da coisa |
| entregável | o que você recebe |

## Expressões para cortar

Quase sempre não acrescentam nada. Apague e leia de novo.

- basicamente
- de fato, na verdade
- é importante ressaltar que
- vale lembrar que
- no final do dia
- sem sombra de dúvida
- absolutamente
- literalmente (quando não é literal)
- muito, super, extremamente (antes de adjetivo fraco)
- cada vez mais
- nos dias de hoje, no cenário atual
- por último, mas não menos importante

## Como levar para o TERMINOLOGIA.md

Para cada palavra escolhida, uma linha na tabela de termos proibidos, com as três colunas do template:

```md
| Efetuar | Formal demais para o nosso cliente. | Fazer. |
```

Mantenha a tabela em ordem alfabética. Quando a palavra vier de um caso real (um rascunho que o time corrigiu), registre no `## Histórico de mudanças`.
