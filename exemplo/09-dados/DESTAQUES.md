# Destaques

## Como usar este arquivo

- **O que entra:** os ativos que se saem melhor que os outros. Peças de conteúdo, e-mails, anúncios, vídeos e páginas específicas, com os números que lhes deram um lugar aqui. Este arquivo é material de referência para qualquer agente que escreva conteúdo novo.
- **Como os agentes leem:** os agentes estudam os vencedores antes de escrever. Seguem o padrão do que funciona para esta audiência, não o que funciona num curso genérico de conteúdo.
- **Frequência de atualização:** atualize todo mês. Tire as peças que saírem do quartil de cima. Inclua os novos vencedores.

## Checklist para agentes de IA

- [ ] Legível por máquina: um registro por vencedor, com campos previsíveis.
- [ ] Estruturado: seções por tipo de ativo.
- [ ] Fonte única da verdade.
- [ ] Versionado.
- [ ] Citável: os agentes citam `/09-dados/DESTAQUES.md` quando escrevem a partir de um padrão comprovado.

## Como escolhemos os vencedores

Um vencedor é um ativo que cumpre dois ou mais critérios abaixo:

- Está entre os 10% melhores do seu canal em engajamento ou conversão nos últimos 90 dias.
- Tem pelo menos uma reunião agendada ou um MQO atribuído.
- Foi citado por pelo menos um comprador numa call de vendas como "a peça que me fez agendar".
- Foi citado numa resposta de buscador com IA (AI Overview do Google, ChatGPT, Perplexity e afins).

## Exemplo

### Cadência: post do blog com melhor desempenho

- **Título:** "Como diminuir a inadimplência no estúdio de pilates sem virar cobradora no WhatsApp."
- **URL:** `/blog/inadimplencia-estudio`
- **Período:** janeiro a março de 2026.
- **Métricas principais:** 3.100 sessões orgânicas, 14 demonstrações agendadas atribuídas, trecho em destaque conquistado no Google para "como diminuir inadimplência em academia", citado no AI Overview.
- **Por que funciona:**
  - O H1 repete a pergunta exata da dona de estúdio.
  - Um bloco de definição de 40 a 60 palavras nas primeiras 300 palavras.
  - Régua de cobrança (lembrete, Pix automático, aviso, bloqueio da agenda) numa tabela que outros sites não publicam.
  - Citação de depoimento autorizado no meio do texto, de uma dona de estúdio com nome e cidade (T-001).
  - Bloco de perguntas frequentes com dados estruturados `FAQPage`.
- **Padrão para reaproveitar:** dor concreta da dona de estúdio + tabela prática própria + perguntas frequentes visíveis.

## Como passar este arquivo para um agente de IA

```text
Carregue /09-dados/DESTAQUES.md antes de escrever uma peça nova para o mesmo canal.

Fluxo:
1. Escolha os dois ou três vencedores mais próximos neste arquivo.
2. Anote o padrão do gancho, a estrutura, o padrão de prova e o CTA.
3. Escreva uma peça nova que siga o padrão sem copiar o conteúdo.
4. Depois de publicar, inclua a peça em /08-conteudo/BIBLIOTECA.md e marque-a para a revisão mensal. Se ela entrar nos 10% melhores, promova-a para este arquivo.

Cite /09-dados/DESTAQUES.md no briefing quando usar um padrão daqui.
```

Caminhos de referência: `/09-dados/DESTAQUES.md`, `/09-dados/MEDICAO.md`, `/08-conteudo/BIBLIOTECA.md`, `/10-cerebro/prompts/`.
