# 08, Biblioteca de conteúdo, provas e calendário editorial

O site já tem mapa. Os dados estruturados já estão no lugar. Agora é hora de encher o site e os canais com substância.

## O que esta camada faz

Três arquivos e um modelo ocupam esta pasta. Juntos, guardam cada peça de conteúdo que você produz, cada depoimento que você pode citar e cada semana do seu plano de publicação.

- `BIBLIOTECA.md` é o inventário de todos os ativos: posts de blog, guias, vídeos, podcasts, webinars, iscas digitais, cases. Se não está na biblioteca, não existe.
- `CALENDARIO.md` é o plano contínuo de 90 dias. Semanas, canais, formatos, responsáveis e status.
- `PROVAS.md` é o banco de depoimentos, cases, avaliações e conteúdo gerado por clientes. Os agentes citam a partir deste arquivo.
- `modelos/estudo-de-caso.md` é o roteiro para preencher cada case.

## Arquivos desta pasta

- `BIBLIOTECA.md`
- `CALENDARIO.md`
- `PROVAS.md`
- `modelos/estudo-de-caso.md`

## Ordem de construção nesta camada

1. Comece pela `BIBLIOTECA.md`. Faça o inventário do que já existe. Arquive o que morreu. Atualize o que envelheceu.
2. Preencha a `PROVAS.md`. Toda afirmação que você quer fazer precisa de uma prova citada.
3. Planeje o `CALENDARIO.md` com 90 dias de antecedência.
4. Use `modelos/estudo-de-caso.md` sempre que a história de um cliente estiver pronta.

## O que esta pasta alimenta

- `09-dados` mede o desempenho de tudo o que está na biblioteca de conteúdo.
- `10-cerebro` carrega as provas e o ritmo editorial nos fluxos dos agentes.
