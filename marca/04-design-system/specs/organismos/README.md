# Organismos

Componentes compostos maiores, formados por moléculas e átomos: navegação, tabela, cabeçalho de página, painel de conteúdo, grade de cards, rodapé do site.

## Vazia de propósito

Esta pasta vem vazia para você não cair na tentação de copiar specs velhas que talvez não batam com a sua interface. Acrescente os organismos que o seu produto realmente usa, com o modelo em [`../../MODELO-DE-SPEC.md`](../../MODELO-DE-SPEC.md).

## Ordem sugerida para produtos de pequenas e médias empresas

1. `navegacao.md` (navegação principal + navegação no celular + regras de estado ativo)
2. `rodape-do-site.md`
3. `cabecalho-de-pagina.md` (título + metadados + área de ações)
4. `tabela-de-dados.md` (linha de cabeçalho, estados das linhas, ordenação, ligação com a paginação)
5. `grade-de-cards.md`
6. `topo-de-landing-page.md` (referência para qualquer landing page)
