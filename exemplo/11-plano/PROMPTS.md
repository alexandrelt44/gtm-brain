# Prompts para o seu assistente de IA

Quando o plano cabe numa página, ele vira a coisa mais útil que você pode entregar a um assistente de IA. Ele transforma "me ajuda com marketing" em "me ajuda a trazer 667 visitas qualificadas por mês do Google para um plano que precisa de 200 clientes novos". O assistente para de adivinhar suas metas e começa a trabalhar nas que você escreveu.

Cada prompt é uma linha só, que você cola do jeito que está em qualquer assistente. Cada um tira os detalhes do seu plano, então não precisa editar. Troque `[cole o plano]` pelo seu plano de uma página preenchido e, no terceiro prompt, preencha os números do mês passado.

## 1. Peça para conferir sua conta

```
Este é o meu plano de marketing de uma página: [cole o plano]. Confira cada cálculo, diga quais entradas parecem otimistas para um negócio como o meu e por quê, e liste as três premissas que mais prejudicariam o plano se estiverem erradas.
```

## 2. Peça para transformar a meta de cada canal numa lista de tarefas do mês

```
Este é o meu plano de marketing de uma página: [cole o plano]. Para cada canal da tabela, escreva as tarefas específicas que o dono deve concluir este mês para bater a meta de visitas daquele canal, em ordem de prioridade, com o tempo que cada tarefa deve levar.
```

## 3. Peça para fazer a revisão mensal com você

```
Este é o meu plano de marketing de uma página: [cole o plano]. Estes são os números reais do mês passado: visitas [n], leads [n], clientes [n], gasto [R$]. Compare os números reais com as metas, identifique o primeiro número que falhou lendo de cima para baixo, diagnostique a causa mais provável e recomende uma mudança para o mês que vem.
```

## Onde o assistente não ajuda

Ele não sabe sua taxa de fechamento, sua taxa de conversão nem quanto um cliente vale para você. Esses números vêm do seu CRM e do seu analytics, e tudo o mais depende deles. Dê números reais e ele multiplica seu esforço. Dê chutes e ele multiplica seus chutes.

## Deixe todo prompt melhor

Guarde o plano no mesmo lugar do seu ICP e das outras camadas da marca, num lugar que o assistente consiga ler. As 11 camadas da marca existem para isso, e o [`../10-cerebro/CEREBRO.md`](../10-cerebro/CEREBRO.md) diz ao agente em que ordem carregá-las. Com o plano lá dentro, todo prompt que você escrever no resto do ano fica melhor sem você precisar reescrevê-lo.
