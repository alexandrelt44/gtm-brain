# Assets visuais

Esta pasta guarda os arquivos binários citados em `/03-visual/IDENTIDADE-VISUAL.md`. O modelo vem vazio porque arquivos de logo, fotos da marca e fontes licenciadas são próprios de cada empresa.

## Arquivos esperados

Coloque os arquivos abaixo aqui quando adaptar este modelo para a sua marca.

### Logos

- `logo-principal.svg`: logo principal em cores.
- `logo-principal.png`: logo principal em 2x, para onde SVG não é aceito.
- `logo-secundario.svg`: variante horizontal ou empilhada.
- `logo-monocromatico.svg`: versão em uma cor para fundos carregados.
- `logo-monocromatico-branco.svg`: versão branca para fundos escuros.
- `logo-simbolo.svg`: só o símbolo, para favicons e avatares de redes sociais.
- `favicon.ico`: favicon combinado em 16x16 e 32x32.
- `apple-touch-icon.png`: 180x180 para a tela inicial do iOS.

### Fotos da marca

- `topo-01.jpg`: foto aprovada para o topo do site, 2560x1440.
- `topo-02.jpg`
- `topo-03.jpg`

### Molduras de dispositivo

- `molduras-de-dispositivo/notebook-claro.png`
- `molduras-de-dispositivo/notebook-escuro.png`
- `molduras-de-dispositivo/celular-claro.png`
- `molduras-de-dispositivo/celular-escuro.png`

### Fontes (se auto-hospedadas)

- `fontes/display/`: arquivos da família display.
- `fontes/texto/`: arquivos da família de texto.
- `fontes/mono/`: arquivos da família mono.

Inclua o texto da licença da fonte em cada pasta de fonte.

### Registro de imagens geradas

- `registro-de-geracao.md`: acrescente aqui cada imagem gerada por IA, com o prompt, a ferramenta, a data e o caso de uso.

## Não versione

- Nenhuma fonte licenciada sem licença comercial que permita redistribuição.
- Nenhuma foto de banco de imagens sem licença comercial.
- Nenhuma foto de cliente sem autorização por escrito.
- Nenhum arquivo bruto de alta resolução acima de 10 MB. Use uma CDN ou um sistema de gestão de assets (DAM).

## Lembrete de acessibilidade

Toda variante do logo precisa passar na checagem de contraste de 3:1 contra o fundo em que vai aparecer. Deixe as versões monocromáticas prontas para situações de baixo contraste.

Caminhos de referência: `/03-visual/IDENTIDADE-VISUAL.md`, `/03-visual/IMAGENS.md`, `/03-visual/PROMPTS-DE-IMAGEM.md`.
