# Clusters de conteúdo e arquitetura de conteúdo

## Como usar este arquivo

- **O que entra:** o mapa hub-and-spoke de cada página pilar e dos seus satélites. Planos de links internos. Lacunas de conteúdo.
- **Como os agentes leem:** os agentes carregam este arquivo quando propõem um post novo, para saber onde ele se encaixa, para onde ele aponta e qual pilar ele sustenta.
- **Frequência de atualização:** revise a cada trimestre. Um cluster com menos de seis satélites está incompleto. Um cluster com mais de quinze provavelmente são dois clusters.

## Checklist para agentes de IA

- [ ] Legível por máquina: mapa de clusters numa estrutura de árvore previsível.
- [ ] Estruturado: página pilar, lista de satélites, plano de links internos, lacunas de conteúdo.
- [ ] Fonte única da verdade: nenhum outro mapa de conteúdo num documento paralelo.
- [ ] Versionado: data da última atualização.
- [ ] Citável: os agentes citam `/06-seo/CLUSTERS.md` em todo briefing de conteúdo.

## Modelo hub-and-spoke

- **Página pilar:** de 2.500 a 4.500 palavras. Cobre um tema principal de forma ampla. Tem uma pessoa dona.
- **Satélites:** de 1.000 a 2.000 palavras cada. Cada satélite aprofunda um subtema. Aponta para o pilar. Aponta para pelo menos dois satélites irmãos.
- **Cluster:** um pilar mais seis a doze satélites. Cobre uma disciplina ou um problema de uma persona.

## Regras de links internos

Valem para todos os clusters.

- Todo satélite aponta para o pilar nas primeiras 200 palavras e de novo na conclusão.
- Todo satélite aponta para pelo menos dois satélites irmãos, de preferência dentro do texto e não num bloco de "posts relacionados".
- Toda página pilar aponta para todos os seus satélites numa única seção perto do meio da página.
- Todo cluster aponta lateralmente para pelo menos um cluster vizinho, para que os buscadores enxerguem a estrutura.

## Lacunas de conteúdo

Liste as lacunas por cluster.

- **[Cluster 1]:** [Subtema ainda não coberto]
- **[Cluster 1]:** [Pergunta que aparece em avaliações de clientes e ainda não tem resposta]
- **[Cluster 2]:** [Pergunta da seção "As pessoas também perguntam" das palavras-chave alvo que ainda não foi respondida]

## Cadência de atualização

- Toda página pilar é atualizada a cada 6 meses.
- Todo satélite é atualizado a cada 12 meses, ou antes se o tráfego cair 25% ou mais de um mês para o outro.
- Checklist de atualização: atualizar números, conferir de novo as afirmações, trocar prints de tela, refazer a pesquisa da palavra-chave, reescrever a abertura se ela ainda começa com "nos dias de hoje...".

## Exemplo: Cadência

### Cluster 1: Inadimplência e cobrança no estúdio

**Página pilar:**

- Título: Como diminuir a inadimplência em academia e estúdio (guia 2026)
- URL: `/blog/como-diminuir-inadimplencia`
- Palavra-chave principal: "como diminuir inadimplência em academia"
- Recurso da SERP: trecho em destaque + citação em visão geral criada por IA
- Tamanho: 3.400 palavras

**Satélites:**

1. Pix automático para estúdios: como funciona a cobrança recorrente, `/blog/pix-automatico-para-estudios`
2. Cobrar aluno pelo WhatsApp: o que funciona e o que desgasta a relação, `/blog/cobrar-aluno-pelo-whatsapp`
3. Cartão recorrente ou Pix automático: qual usar no estúdio, `/blog/cartao-recorrente-ou-pix-automatico`
4. Política de cancelamento: modelo para estúdio de pilates, `/blog/politica-de-cancelamento-estudio`
5. Como reajustar a mensalidade sem perder aluno, `/blog/reajuste-de-mensalidade`
6. Reposição de aulas: regras que reduzem falta e cancelamento, `/blog/reposicao-de-aulas`
7. Nota fiscal no estúdio: o que emitir para cada aluno, `/blog/nota-fiscal-no-estudio`
8. Como montar uma régua de cobrança para estúdio pequeno, `/blog/regua-de-cobranca-estudio`

**Mapa de links internos:**

- O pilar aponta para os 8 satélites numa seção "para aprofundar", por volta de 60% da página.
- Os satélites 1, 3 e 8 aparecem na seção "como cobrar" do pilar.
- Os satélites 4, 5 e 6 aparecem na seção "regras do estúdio" do pilar.
- Todo satélite abre com uma definição de uma frase que aponta para o pilar.
- Os satélites 1 e 3 apontam um para o outro. Os satélites 4 e 6 apontam um para o outro.

**Lacunas de conteúdo:**

- "Como cobrar o aluno de plano anual que quer cancelar no meio do contrato."
- "O que acontece com o Pix automático quando o aluno troca de banco."

## Como passar este arquivo para um agente de IA

```text
Carregue /06-seo/CLUSTERS.md antes de propor qualquer conteúdo novo.

Antes de escrever:
1. Identifique a qual cluster a peça pertence.
2. Confirme que a palavra-chave principal ainda não foi atribuída a um satélite irmão.
3. Planeje os links internos: para o pilar, para dois satélites irmãos e para pelo menos uma página de serviço ou uma prova.
4. Confira a lista de lacunas de conteúdo. Se o tema se sobrepõe a uma lacuna, preencha a lacuna.

Não publique uma peça sem cluster pai. Se o tema não se encaixa, proponha um cluster novo antes de escrever.

Cite /06-seo/CLUSTERS.md no briefing do conteúdo.
```

Caminhos de referência: `/06-seo/CLUSTERS.md`, `/06-seo/PALAVRAS-CHAVE.md`, `/06-seo/GEO-AEO.md`, `/07-site/MAPA-DO-SITE.md`.
